# Artist & Art Director Portfolio

## About the Project

This project is a personal portfolio website showcasing my work as a visual artist and art director. It highlights my pointillism artwork, creative direction, film projects, visual storytelling, and artistic achievements through a visually engaging and responsive design.

## Features

- Showcase of original artwork and creative projects
- Art direction and film project presentation
- Responsive design for desktop, tablet, and mobile devices
- Elegant layout focused on visual storytelling
- Contact and social media links

## Technologies Used

- React
- JavaScript
- CSS
- Vite

Currently in development.
